From no MCP to MCP magic in minutes.

Paste a Python function. We lint it, encrypt it at rest, run it sandboxed in WebAssembly, and expose it as a real MCP tool behind one endpoint — no Dockerfile, no deploy, no infra to babysit.

word_count.py 
def word_count(text: str) -> dict:
    words = [w for w in text.split() if w]
    return {"words": len(words), "characters": len(text)}
